# tago-shoppingmall-prototype

tagoplus 쇼핑몰 **관리자(Admin) 전체 기획서 겸 HTML 프로토타입**입니다.
단일 HTML 파일로, 서버·빌드 없이 브라우저에서 바로 실행됩니다.

## 열기
- 로컬: `index.html`을 브라우저로 열기
- GitHub Pages(설정 시): `https://nbjiu1011.github.io/tago-shoppingmall-prototype/`

## 구성
- 10개 대메뉴 / 약 44개 화면 (주문배송·상품관리·고객/문의·프로모션·디자인·게시판·매출분석·접속통계·환경설정)
- 화면별 기획 노트 + 필터/목록/폼/통계 와이어프레임
- 클릭 인터랙션: 행 상세·수정·삭제·추가 모달, 저장 토스트
- 다크/라이트 테마, 모바일 반응형

> 데이터는 레이아웃 확인용 샘플이며 실제 DB 연동이 아닌 프로토타입입니다.
